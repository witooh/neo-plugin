# neo-dev-toolkit

Opinionated Claude Code plugin: **`neo`** is the `using-agent-skills` meta-skill in a customized form, wrapped in loop engineering — it forks the upstream discovery router and drives it as a recursive goal that runs first on every invocation (frame the goal + an observable exit condition into a `STATE.md` before touching source, drive the lifecycle phases in order itself, never a pick-your-methodology menu — a skipped phase is a recorded waiver, not a silent skip, so a feature can't quietly ship with no design doc; a large feature gets one plan checkpoint after Plan — verify with a fresh-context maker-checker, hand off at a human gate — concept from Addy Osmani's _loop engineering_), backed by an `ingest` memory primitive, GitLab/Atlassian connectors, API-doc tooling, and Go service scaffolding/migration.

> **Prerequisite:** the lifecycle skills that `neo`'s router points to are **not** bundled here — they ship in the upstream **[agent-skills](https://github.com/addyosmani/agent-skills)** plugin, which you install separately. See [Prerequisite](#prerequisite--the-upstream-agent-skills-plugin) below.

## Installation

### Claude Code (plugin marketplace)

Install the plugin straight from this GitHub repo — no local clone needed:

```bash
# From inside Claude Code
/plugin marketplace add witooh/neo-plugin
/plugin install neo-dev-toolkit@neo
```

`witooh/neo-plugin` is the GitHub `owner/repo` shorthand. Claude Code reads `.claude-plugin/marketplace.json` from the default branch and resolves the plugin from there.

To update:

```bash
# 1. Pull the latest marketplace listing from GitHub
/plugin marketplace update neo

# 2. Reinstall so the new plugin version is loaded
/plugin uninstall neo-dev-toolkit@neo
/plugin install neo-dev-toolkit@neo
```

Open a fresh Claude Code session to confirm the updated skills are active.

### Other agents (skills CLI)

For Cursor, Windsurf, opencode, Codex, and 70+ other agents — or Claude Code without the plugin marketplace — install the skills with Vercel Labs' [`skills`](https://github.com/vercel-labs/skills) CLI:

```bash
npx skills add witooh/neo-plugin
```

This scans every `skills/<name>/SKILL.md` in this repo and copies it into your agent's skills directory (`.claude/skills/` or `.agents/skills/`); re-run the same command to update. It installs the **skills only** — not the `SessionStart` hook — so they are not suggested proactively; invoke them by name (`neo`, `ingest`, …). The upstream agent-skills [prerequisite](#prerequisite--the-upstream-agent-skills-plugin) still applies.

## Prerequisite — the upstream agent-skills plugin

`neo` **forks** the **`using-agent-skills`** router — skill discovery, the 6 Core Operating Behaviors, the spec→ship lifecycle, and the verification methodology — and wraps it in a loop, but the lifecycle SKILLS that router points to are not embedded. Those 24 lifecycle skills, 4 specialist agents, and 8 slash commands live in the upstream **[agent-skills](https://github.com/addyosmani/agent-skills)** plugin — **not in this repo**. This toolkit no longer bundles them.

**Install the upstream agent-skills plugin first** (follow that repo's README for its marketplace + install commands). Without it, the lifecycle skills neo routes to are missing, and the `/spec` `/plan` `/build` `/test` `/review` `/ship` `/code-simplify` `/webperf` commands plus the `code-reviewer` / `security-auditor` / `test-engineer` / `web-performance-auditor` agents are unavailable.

This toolkit ships only the **neo-toolkit** skills (the table above): the neo loop, the `ingest` memory primitive, the GitLab/Atlassian connectors, the api-doc chain, and the Go scaffolding/migration skills.

## Companion pieces

- `/neo <task>` — invokes the `neo` loop skill directly
- `SessionStart` hook — injects a short reminder on `startup | clear | compact` so Claude proactively picks the right skill
- The `/spec` `/plan` `/build` `/test` `/review` `/ship` `/code-simplify` `/webperf` commands and the lifecycle skills neo's router points to come from the upstream **agent-skills** plugin (see [Prerequisite](#prerequisite--the-upstream-agent-skills-plugin)), not this repo

## Usage

Three ways to kick off work:

1. **Automatic** — the SessionStart hook tells Claude which skill to reach for; just describe the task naturally
2. **Slash command** — `/neo <task description>` runs the full loop
3. **Direct ask** — "ช่วย review MR นี้...", "gen api spec ให้หน่อย", "/ingest <url>", "migrate project นี้ให้เข้าโครง"
